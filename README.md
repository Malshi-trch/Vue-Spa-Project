# Recipe Book - Vue 3 Single Page Application

A modern, data-driven Recipe Book SPA built with Vue 3, TypeScript, and Tailwind CSS, consuming data from the DummyJSON API. Developed as part of the CS3404 GUI Programming Mini Project[cite: 1].

## Features
- **Responsive Layout:** Optimized grid layouts for mobile, tablet, and desktop views using Tailwind CSS[cite: 1].
- **Dynamic Search & Filtering:** Filter recipes instantly by category, tags, or search queries[cite: 1].
- **Detailed View:** Interactive modal/panel view displaying ingredients, step-by-step instructions, prep/cook times, and ratings[cite: 1].
- **Bookmarks & Favorites:** Save your favorite recipes with persistent state management[cite: 1].
- **Dark Mode Support:** Toggle seamlessly between Light and Dark themes[cite: 1].
- **Authentication Simulation:** Mock login and session state handling[cite: 1].

---

## Tech Stack
- **Framework:** Vue 3 (Composition API)[cite: 1]
- **Language:** TypeScript[cite: 1]
- **Styling:** Tailwind CSS[cite: 1]
- **Build Tool:** Vite[cite: 1]
- **Data Source:** DummyJSON API (`https://dummyjson.com/recipes`)[cite: 1]
